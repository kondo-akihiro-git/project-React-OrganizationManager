# 所属管理アプリ (Organization Manager)

このアプリは、**社員の所属（部署）と役職を管理するための社内向けツール**です。  
部署・役職・社員名の関係を直感的に可視化し、追加・編集・削除が行えることを目的としています。  

## 主な機能
- 所属（部署）と役職、社員名の一覧表示  
- 一覧の可視化（ReactFlowによる組織図表示）  
- 所属・役職・社員の追加、編集、削除機能  
- 一覧のPDF出力機能  

## 技術スタック
- フロントエンド: **React (TypeScript)**  
  - UI: MUI  
  - 可視化: ReactFlow  
- バックエンド: **FastAPI** (Python)
